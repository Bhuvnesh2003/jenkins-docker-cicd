# AWS example - code only, NOT applied

This folder is an example only.
It is NOT initialized, NOT planned and NOT applied on this host.

Why not applied:
- There is no real AWS account here
- There are no AWS credentials here
- The AWS provider download is heavy and is not needed for this demo

What it shows:
- AWS provider version constraint
- Region and instance type variables
- One example EC2 instance with a Name tag
- AMI has no default, so it cannot be applied by accident

Do NOT run init, plan or apply here without a real AWS account,
real credentials and a real AMI ID from that account.
Any AWS deployment claim in the final report must say code-only,
not live.
